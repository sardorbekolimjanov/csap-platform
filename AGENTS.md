# CSAP Development Instructions

Project:
Computer System Anomaly Prediction Platform

Purpose:
Research and production-oriented platform for
multivariate time-series anomaly detection,
forecasting and explainability.

Architecture:
Frontend: React + TypeScript
Backend: FastAPI + Python
Database: PostgreSQL + TimescaleDB
Monitoring: Prometheus
ML: scikit-learn
Deep Learning: PyTorch
Experiment Tracking: MLflow
Deployment: Docker Compose

Principles:
1. Modular architecture
2. Type safety
3. Test-driven development
4. Reproducible ML experiments
5. No hardcoded secrets
6. No fabricated scientific results
7. No unnecessary dependencies
8. Every major feature must have tests
9. Keep ML code independent from API layer
10. Preserve backward compatibility
